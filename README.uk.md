# idle-status-screen

[English](README.md)

Перетворює неактивний екран входу на дисплей стану системи.

Поки ніхто не увійшов у графічну сесію і певний час (типово 30 с) немає вводу з
клавіатури, миші чи сенсорного екрана, дисплей перемикається з екрана входу
(SDDM чи greeter іншого display manager'а) на віртуальний термінал із системним
монітором — типово **btop**, або htop, atop, top чи будь-яка інша програма.
Будь-який ввід одразу повертає екран входу.

Зроблено для Raspberry Pi 5 із сенсорним екраном і KDE/SDDM, але нічого
специфічного для Pi тут немає.

## Можливості

- Екран стану показується лише коли на передньому плані **greeter** — ніколи
  поверх робочої сесії користувача.
- Пробуджується від **будь-якого** вводу evdev: клавіатура, миша, тачскрін;
  нові пристрої підхоплюються автоматично. Ввід лише спостерігається, не
  перехоплюється.
- Монітор працює **від старту системи** в сесії tmux, тож графіки вже мають
  історію на момент показу.
- Показ **лише для перегляду** через [kmscon](https://github.com/kmscon/kmscon):
  шрифти TrueType із символами брайля (детальні графіки btop) і truecolor.
  Натискання клавіш на екрані стану не потрапляють у програму.
- Монітор працює від непривілейованого системного користувача `_idle-status`.
- **Екран не гасне**: заставку/DPMS у X і DPMS у kmscon вимкнено.

## Встановлення

Завантаж `.deb` зі сторінки [Releases](../../releases) і встанови:

```sh
sudo apt install ./idle-status-screen_*_all.deb
```

Сервіси вмикаються й запускаються одразу.

## Налаштування

Усе в `/etc/default/idle-status`:

| Параметр           | Типово               | Значення                                                    |
|--------------------|----------------------|-------------------------------------------------------------|
| `IDLE_TIMEOUT`     | `30`                 | Секунд без вводу на екрані входу до перемикання             |
| `STATUS_VT`        | `8`                  | Віртуальний термінал для екрана стану                       |
| `MONITOR`          | `btop`               | `btop`, `htop`, `atop`, `top` або будь-яка команда/шлях      |
| `MONITOR_ARGS`     | *(порожньо)*         | Аргументи; порожньо = типові для відомих програм            |
| `KMSCON_FONT`      | `DejaVu Sans Mono`   | Шрифт екрана стану                                          |
| `KMSCON_FONT_SIZE` | `14`                 | Розмір шрифту в пікселях                                    |
| `KMSCON_ARGS`      | `--no-drm`           | Додаткові параметри kmscon (напр. `--rotate=right`)         |

Застосувати зміни:

```sh
sudo systemctl restart idle-status-monitor idle-status-display idle-status-watcher
```

Профіль btop — `/etc/idle-status/btop.conf`, налаштування tmux —
`/etc/idle-status/tmux.conf`. Лог (який пристрій розбудив екран):
`journalctl -u idle-status-watcher`.
